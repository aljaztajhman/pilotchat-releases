# PilotChat releases

Windows installers and automatic updates for PilotChat, a private work chat with Claude built in. This repo holds only the installer files; the source code is private.

## Install

1. Open the [latest release](https://github.com/aljaztajhman/pilotchat-releases/releases/latest) and download `PilotChat-Setup-x.y.z.exe`.
2. Run it. Windows may show "Windows protected your PC" because the installer isn't code-signed yet. Click **More info**, then **Run anyway**.
3. Sign in with your email. You'll get a one-time code by email. Only invited addresses can sign in.
4. For `@claude` to run on your PC, install [Claude Code](https://code.claude.com/docs/en/setup) and sign in with your own Claude plan.

PilotChat updates itself after that. When an update is ready you'll see a "Restart to update" banner.
